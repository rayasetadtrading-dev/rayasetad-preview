# rayasetad-preview

پیش‌نمایش آفلاین وب‌سایت رایاستد برای بازبینی داخلی.

این مخزن سایت اصلی (rayasetad.com) نیست و هیچ تغییری روی وردپرس اعمال نمی‌کند.
صفحات با `noindex,nofollow` و `robots.txt` از ایندکس موتورهای جستجو کنار گذاشته شده‌اند، اما مخزن عمومی است و هرکس لینک را داشته باشد می‌تواند پیش‌نمایش را ببیند.

GitHub Pages: https://rayasetadtrading-dev.github.io/rayasetad-preview/
